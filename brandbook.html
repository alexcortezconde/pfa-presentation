Design

This document defines the visual language of DECK — our typographic hierarchy, color philosophy, component library, and motion principles. Every decision here exists for a reason.

01

Colors

The palette is intentionally minimal. One deep background, one warm text tone, one red that carries all the visual heat. Restraint is the system.

Void
Page background. The foundation everything sits on. Near-black, not pure black — keeps depth without harshness.
--bg
Surface
Hover state, elevated cards. Barely perceptible lift from background — used sparingly for depth.
--surface
Border
Dividers, grid gaps, structural lines. The quiet skeleton that holds layout together.
--border
Ivory
Primary text. Warm off-white — softer than pure white, avoids the harshness of stark contrast. All headlines and body copy.
--ivory
Vermillion
The only accent. Used for tags, line decorations, numbers, interactive underlines, and CTA buttons. Never diluted.
--red
Vermillion Dim
Background tint for code tokens, badges, and pill labels. Low-opacity to suggest accent without competing.
--red-dim
Do
  • Use red only for single points of emphasis
  • Keep text on --bg or --surface only
  • Use --ivory-60 for secondary text
Don't
  • Add new accent colors to the system
  • Use pure #FFFFFF or #000000
  • Use red for decorative purposes only

06

Principles

The rules behind the rules. These are the non-negotiable beliefs that anchor every visual decision in this system.

— 01
One Accent

Vermillion red is the only color with expressive weight. If everything is accented, nothing is. Use it once per composition — where the eye should land first.

— 02
Earn Space

Empty space is not wasted space. Each element must justify its presence. Before adding anything, ask: does removing this make the design better? Often the answer is yes.

— 03
No Noise

Decorative elements serve structure. The grain texture, ghost numbers, and red line all carry spatial or navigational meaning. Decoration without function is forbidden.

— 04
Type Is Layout

Headlines are shapes before they are words. At display size, Bebas Neue creates mass and rhythm. Design the type first; everything else is annotation.

— 05
Motion Is Signal

Animation communicates sequence and hierarchy, not delight. The red line ascending on slide entry tells you: something new has started. Stagger tells you: read in this order.

— 06
Contrast Is Clarity

The near-black background and warm ivory type create contrast that guides attention effortlessly. Never soften this contrast to seem sophisticated. Clarity is sophistication.

The System Is the Message

A brand guide that looks different from the brand it describes has failed. Every page, font choice, and motion curve in this document uses the exact same tokens as the presentation it governs.
